# Eskillows — loja online

Interface da loja Eskillows com catálogo, busca e filtros, páginas de produtos, carrinho e telas de login/cadastro.

## Como abrir

1. Extraia a pasta `Venda_Tecnologia_melhorado`.
2. Abra essa pasta como raiz no VS Code.
3. Abra `HTML/index.html` diretamente no navegador ou use uma extensão de servidor local.

Os links entre páginas são relativos, então carrinho, produtos e autenticação funcionam tanto ao abrir o arquivo diretamente quanto em um servidor local.

## Sobre a autenticação

A API ainda não está integrada. As telas de login e cadastro validam os campos e mostram mensagens de estado, mas não autenticam usuários, criam contas nem armazenam senhas.

## Interface

A atualização preserva a logo e os recursos originais, reorganiza catálogo, detalhes de produto, carrinho e autenticação e adapta a apresentação a telas menores. As rotas, imagens, integração local de estoque/carrinho e validações existentes foram mantidas.

O catálogo apresenta duas opções de fone, teclado, mouse, microfone, mouse pad e cadeira. Cada par mantém o mesmo preço, e as opções são identificadas separadamente no estoque e no carrinho. A Caixa de Som Gamer está disponível por R$ 170,00 e a Webcam Full HD por R$ 120,00.

O banner inicial destaca o mouse pad do dragão e usa quatro imagens com enquadramento completo para valorizar os produtos.
